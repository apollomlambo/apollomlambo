# Hi, I'm Apollo Mlambo 👋

**Forward Deployed AI Engineer** · Cape Town, South Africa

I work embedded with client teams to take ambiguous business problems to production AI systems in weeks. My focus is agentic systems: multi-agent orchestration, RAG, MCP tool layers and multi-provider model pipelines, built inside the client's own architecture, security and governance standards.

7+ years of engineering, from full-stack and Java enterprise systems at Shoprite, BMW and Standard Bank to production agentic AI at Inference Group.

## 🔭 What I'm working on

- **Operater Assistant (UK telecoms operator):** a coordinator agent with specialist sub-agents that watch delivery milestones and draft supplier chases. Gemini on Vertex AI with a switchable Claude provider, an MCP and AI gateway layer on GKE, read-only BigQuery access, and human approval before anything is sent.
- **People Capability Agent (global advisory firm):** a Workday-first agent that assesses skills and roles, enriched with external skills data.
- **Multi-Tenant Consulting Operations Platform:** Next.js, tRPC and Azure PostgreSQL with Entra ID and RBAC across seven companies, Claude-powered candidate screening, and Xero and HubSpot integrations.
- **AI Voice Agent:** a phone agent on ElevenLabs and OpenRouter for outbound and inbound calls.
- **Automated Content Pipeline:** OpenRouter, ElevenLabs, Supabase and GitHub Actions, with an analytics feedback loop.

## 🧠 Previous work

- **AI Research Analyst Platform:** an autonomous research agent that breaks problems into 20+ subqueries, with contradiction detection and citation-ready reports.
- **TalentIQ:** RAG talent matching on Gemini, text embeddings and Supabase pgvector, orchestrated in n8n.
- **Loan Rescheduling Automation:** Outlook to SharePoint to Dataverse, with Finacle SOAP integration for real-time account validation.
- **Adverse Media Detection (Standard Bank):** Azure AI services and data pipelines supporting KYC and financial-crime compliance.
